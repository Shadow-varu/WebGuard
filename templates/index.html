Free Web Security Scanner

WebGuard is a web-based security analysis tool designed to help developers, students and security enthusiasts understand the security posture of a website through passive and non-destructive checks.

The scanner analyzes HTTPS configuration, SSL/TLS certificate information, HTTP security headers, cookies, CORS configuration, DNS records, detected technologies, common TCP ports and selected passive security findings.

HTTPS & SSL/TLS

Check HTTPS status, TLS version, certificate information and expiry.

Security Headers

Analyze CSP, HSTS, X-Frame-Options, Referrer-Policy and other headers.

Cookie Security

Review Secure, HttpOnly and SameSite cookie attributes.

CORS Analysis

Inspect common CORS response headers and wildcard configurations.

DNS Analysis

Inspect A, AAAA, MX and NS DNS records.

Technology Detection

Identify selected web technologies from headers and page content.

OWASP-Style Checks

Review selected security controls using practical OWASP-aligned checks.

Passive Recon

Inspect robots.txt, sitemap information and common subdomain responses.

Security Reports

Export scan results as HTML and PDF reports for documentation.

WebGuard provides automated security observations and should not be treated as a complete penetration test or guarantee that a website is secure.
